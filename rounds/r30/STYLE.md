# 后台设计语言 · STYLE.md v32.0（R30「收敛」）

> 唯一样式表：`app.css`（R28 规则 + R29 面板层 / 动效层 + 文件末尾「R30 收敛层」，后者覆盖前者）。
> 本轮依据：R29 在运营待办得 60（R28 65），无批注。并排诊断（r28 / r29 六页 + 脚本量化）结论见 `spec.html`「R29 为什么退步」：一个对象被拆成多张卡、间距只有 16 一档、列表组头变成内缩小条、画布偏暗露得多、订单页少 4 行、首屏动画过多。补充案例：Linear 当前版、Plain、Attio、Catalyst、shadcn sidebar-inset / dashboard-01、Tremor、GitHub 议题；以及 inspiration-log 2026-10-19。
> 方向不变：Linear 式 · 鸢尾强调色 · Geist 数字 · 只用无衬线 · 分组明显 · 控件全平 · 低视觉噪音 · 无绿色识别色。

## 1. 外壳与面（R30 改）
- 画布与侧栏同色 `--color-frame #F5F5F7`（R29 #F2F2F6）；队列 / 记录页露出画布 ≤ 8%。
- **壳先于卡**：工作区按对象分成 2–3 块面——列表面板 `pane card` | 对象 `.sheet` |（右栏 `.sheet`）。
- **一个对象 = 一块面 `.sheet`**：白面、1px `--color-card-line`、圆角 10、极淡投影。内部分区（概况 / 明细 / 动态……）写成 `.card`，但在 `.sheet` 里自动去掉边框、投影和底色；分区之间是左右内缩 20 的 1px 分隔线 + 区块间距；面内表格也内缩 20，和分隔线同宽。操作条 `.cf` 是面的最后一个子元素，滚动时贴底。
- **同类并列才用卡**：一排同类、可比较、各自独立的东西——看板指标格、图表卡、排行卡、区域 / 提醒小卡。一个对象的几个部分不成卡。
- 看板 / 订单用 `.tiles` + `.grid` + 卡片；订单指标格用 `.tiles.compact`（数字 20、说明同一行）。

## 3. 面板规则（与 spec.html R1–R11 对应）
1. **一个对象 = 一块面**：标题、属性、明细、动态是同一块面里的分区（14/600 小标题 + 内缩线 + 间距）。
2. **同类并列才用卡**。
3. **间距三级**：面内 20 › 面间 12；区块间 32（≥ 2.5 × 面间）。
4. **列表组头用贯穿色带**（36px，状态图标 + 组名 + 计数，可折叠）。
5. **操作条贴在对象底部**（后果说明 + 按钮，sticky）。
6. **画布浅、露得少**（#F5F5F7，≤ 8%；看板例外）。
7. 面 / 卡靠 1px 描边成形，投影几乎看不见。
8. 状态颜色只给 14px 图标；红色只给越线数字和危险操作。
9. 控件全平：28px、圆角 6、1px 描边；投影只给浮层。
10. 图表卡先给结论数字，再给图。
11. **表格数值细节**：编号 / 时间等宽；长编号中间省略；金额右对齐、固定两位小数、¥ 与角分降一级灰；多值列「首项 + N 个」。
- R28 / R29 其余规则保留：单行 40 / 表格 36、属性行、完成即退场（灰勾 + 次要色）、迷你柱不上色、指标格即图表页签、高频操作写快捷键、选中谁详情就是谁。

## 4. 动效规则（与 spec.html M1–M7 对应）
1. 页签下划线 / 分段底块 160ms 滑动。
2. 悬停只改底色、文字色、描边色，100ms；面和卡不响应悬停（可点的指标格描边除外）。
3. 展开收起 240ms（grid-template-rows 0fr → 1fr，收起后内容不可聚焦）。
4. 抽屉从右侧滑入 280ms、退出 240ms，6% 遮罩，Esc / 点遮罩关闭，关闭后 inert。
5. **骨架卡壳先行，只在真等待时**：面 / 卡和标题始终在位，只有内容区 `[data-sk]` 变骨架；只在看板首屏（页面声明 `data-load`）、切范围、切页签时出现。
6. 数字只在变化时动一次（看板首屏、切范围）。
7. **首屏不表演**：本地数据的页面打开即是终态；不做卡片错开入场。动效只回应操作和真实等待；切换条目时变化的区域 160ms 淡入。
- 减少动态效果：CSS 时长 / 延迟归零；JS（`RM`）跳过骨架、滚数、入场，直接终态。

## 5. 组件
R28 / R29 组件全部保留。R30 新增 / 改：`.sheet`（一块面；内部 `.card` 为分区；`.ci` 内容组；`.grid` 并排分区用竖线分）· `.tiles.compact` · `.stack>.sec` 区块间距 · `.card .gh.band` 恢复贯穿 · `body[data-load]` 首屏卡壳骨架 · 图片内描边（`img.av` `.thumb img` `.post img` `.pimg`）。
