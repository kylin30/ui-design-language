六个演示：壳先于卡。

R30「收敛」：队列和记录页是「列表面板 + 一块面讲一个对象」，只有同类并列的东西（看板指标格、图表、排行）才是卡；间距三级 20 / 12 / 32。动效只回应操作和真实等待，系统开启「减少动态效果」时全部关闭。每页右上角可换主题（含深色星蓝），按 / 或 ⌘K 打开命令面板。

运营待办参考：Linear 我的事项 + Catalyst 订单详情

左：列表面板，组头恢复贯穿色带，「今天已办」可展开。右：一块面讲一个任务——标题、属性、明细 / 清单、动态是同一块面里的分区（小标题 + 内缩线），操作条贴在底部。换任务时详情 160ms 淡入。

订单售后参考：Stripe 发票列表 + 指标格

4 个紧凑指标格（数字和说明同一行）+ 一张表格卡，首屏 17 行；切页签出行骨架；点行滑出抽屉。

数据看板参考：Stripe 指标格 + Vercel 图表卡

同类并列才用卡：4 个指标格（即图表页签）、图表卡、区域 / 提醒小卡、排行卡；排行与上方隔 32（区块间距）。首屏卡壳先行，只有内容区骨架。

运维告警参考：Sentry 问题流 + Linear 事项详情

告警列表面板 + 一块面讲一条告警：概况、P99（先给结论数字）、分布、经过是分区，「切换到备用通道」贴底。

客户管理参考：Linear 客户页 + Attio 右栏

主记录一块面（概况、需求、席位 + 动态并排），右栏一块面（联系人、合同、下一步）。

内容审核参考：Plain 收件箱 + GitHub 议题

队列面板 / 中栏一块面（原文、机器判断、处理方式）/ 右栏一块面；J / K / 1–3 / Enter 流转，中栏右栏同步淡入。
