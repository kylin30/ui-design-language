# 后台设计语言 v27.0 · Round 25「质感」

方向 A「精简」+ 轻容器 + 材质层。R24「回正」55 分（R23 40 分），批注是「少一点高级感、质感、设计感。」可读性和分组过关，所以 R25 的结构与 R24 完全相同（指标面板、分组列表、画布上的面板），只在最上面加一层统一的材质：`material.css`，最后加载。调研、实测数值和三轮比对见 craft.md 和 craft/*.png。

## 原则
1. 成组：组内间距不超过组间的一半（组间 ÷ 组内 ≥ 2）；间距由内向外逐层加大。
2. 一个对象一个面板：标题、内容、操作同在一块白色面板里；面板里不再套面板，最多一层浅底“井”。
3. 两层底色：浅灰画布 + 白色面板（发丝环 + 两层极软投影、圆角 12）。分组优先靠间距，只有“对象”才配容器。
4. 好读（继承 R21）：正文 15、近黑；每屏一个焦点；次要信息悬停或展开才出现。
5. 单色：鸢尾只用于主操作、选中和焦点；状态是圆点 + 文字；黄色只做小点缀。
6. 键盘：⌘K 命令面板，G + 字母跳页。
7. 先归类（R24）：待办 / 告警列表按紧急程度分段，组标题替读者先归好类；指标里的分段条与列表同序同色。
8. 锚点（R24）：每页都是“页头一句结论 → 指标面板 → 工作面板”三层；工作台页也不去掉指标面板。
9. 数据前后一致：页头、指标、页签、表格、分页、侧栏计数说同一个数，并随操作同步更新。
10. 质感（R25）：层级靠透明度和极软的带色投影，不靠实色描边和大阴影；字距、等宽数字、内高光、描边粗细、圆角同心这些小处统一做到位。不用毛玻璃、噪点、光晕、衬线。

## 容器
- 画布 #F5F5F8（R25）；面板白底、无实色描边，用 `--m-e1`（见下方「材质」）、圆角 12。
- 面板头 56（标题 16/600 + 发丝线），面板体内边距 20，面板底（操作条）用浅底 #F7F7F9。
- 井（字段组）#F8F8FB + inset 发丝环、圆角 9、内边距 14/16；面板里最多一层。
- KPI 合成一块面板，格子之间竖线分隔。
- 列表与详情各一块面板，中缝 20；页签放进列表面板头（R24 起与面板头同为 56，同一行的发丝线对齐）；列表比详情短时拉到同底，底部写“已显示 n / m 条”；详情面板高度贴合视口，头和操作条钉住，内容在面板里滚动。
- 工具条：筛选一组靠左（间距 8），操作一组靠右；放在表格面板内的浅底条上。下拉用按钮式 `.dd`（弹出菜单、单选勾、↑↓ / Esc），不用原生 select。

## 列表分段（R24）
- 组标题 `.lgh`：高 32，浅底 surface-subtle，13/500 次要色 + 计数（tertiary），在列表里吸顶；只有“已超时 / 严重”带 6px 红点。
- 运营待办：已超时 / 今天到期 / 之后；运维告警：严重 / 警告 / 其他。组内顺序不变，空组不显示。

## 指标分段条（R24）
- `.kseg`：高 4、段间隔 2，放在指标说明下方 10px；红 = 已超时 / 严重，灰 55% = 今天到期 / 警告，border-strong = 之后 / 其他。
- 顺序和颜色必须与下面列表的分段一致；不用饼图，也不另起一套颜色。

## 材质（R25，material.css）
| 令牌 | iris | midnight | 用在哪 |
|---|---|---|---|
| --color-bg / --color-surface | #F5F5F8 / #FFF | #0B0C10 / #14161B | 画布 / 面板 |
| --m-line / -soft / -strong | 文字色 8% / 5.5% / 11% | 白 7.5% / 5% / 11% | 面板环 / 面板内分隔 / 控件环 |
| --m-ink | 24,20,46 | 0,0,0 | 投影墨色（不用纯黑） |
| --m-e0 | 0 0 0 1px line | 同 | 井、表格外框 |
| --m-e1 | 环 + 0 1px 2px .04 + 0 2px 6px -2px .05 | inset 0 1px 0 白.04 + 环 + 黑 .35/.55 | 面板、侧栏当前项、分段滑块 |
| --m-e2 | 环 + 0 2px 4px .05 + 0 8px 20px -6px .10 | — | 可点卡片悬停 |
| --m-e3 | 环 + 0 4px 8px .06 + 0 16px 40px -8px .18 | inset 白.06 + 环 .09 + 0 16px 48px -8px .7 | 菜单、命令面板、提示、Toast |
| --m-ctl | 0 0 0 1px line-strong + 0 1px 2px .05 | 加 inset 高光 | 次按钮、输入 |
| 圆角 | 标签 6 · 控件 7 · 井 9 · 面板 12 · 浮层 14 | 同 | 内层 ≤ 外层 |
| 动效 | 150ms cubic-bezier(.2,.7,.2,1) | 同 | hover / focus；按下 translateY(.5px) |

- 主按钮：主色 +12% 白 → 主色的竖向渐变，`inset 0 1px 0 rgba(255,255,255,.22)`，深一阶 1px 环，1px 近影。不发光。
- 焦点：`0 0 0 2px surface, 0 0 0 4px primary·45%`。
- 字形：h1 −0.022em；KPI 数字 −0.03em + tabular；单位 500、三级灰；KPI 标签三级灰；金额小数 55%。
- 图标：16px 网格、1.5 描边、圆头圆角。
- 侧栏：品牌块 = 28px 渐变标 + 工作区名 + 副标题 + ↕ 切换器；当前项是浮起的白片（e1），图标主色。顶栏面包屑用 chevron。
- 趋势线 `.kspark`：84×28，1.5px 主色线 + 缓动停点渐变 + 终点圆；只放在趋势本身是信息的指标里。图表面积也用缓动停点渐变。
- 分段控件：凹槽（文字色 5%）+ 浮起滑块（surface + e1）。条形图 6px 胶囊。
- 顶栏滚动后才出现发丝线。

## 尺寸
- 字号：页标题 26/600，面板标题 16/600，组标题 13/600，正文 15/24，KPI 30/600，最小 13。
- 控件高 32、圆角 7；表头 40、行 46；列表行内边距 14/20；首末列内边距 20。
- 布局：顶栏 48，侧栏 232（与画布同底、无分隔线，选中项为白色胶囊），页边 40。

## 颜色（iris 默认）
- 文字 #111114 / #3E3E46 / #5C5C66；主色鸢尾 #6246EA；选中行 3px 鸢尾左条 + 6% 鸢尾底。
- 其他主题：面板同样用 --m-e1；井 = surface-subtle；midnight 为深色（近黑画布、亮一阶面板、顶边高光）。

## 字体
- 只用无衬线。数字用自托管 Geist（Geist Fig），只有 400 / 500 / 600 三个字重；Geist Mono 只用于代码。

## 主题
- 默认鸢尾，另有 cobalt、lake、graphite、daylight、coral、midnight（深色）。换主题只换色值，不改结构。
