# 后台视觉规范 v8.0（Round 6 ·「墨栏·暖绢」）

> **一句话**：与 UI 库无关的后台视觉规范。用 Ant Design、Element Plus、shadcn/ui、MUI 还是手写 CSS，照着做出来都是同一个产品。气质：**冷静、专业、整齐**。
>
> v8.0 是一次**换身份、不换性格**的改版：R3/R5 的安静规则全部保留，但把“白纸浮在灰画布上、卡里套卡”的外形换成**墨色框架 + 暖绢纸面 + 先排要办的事**。

---

## 0. 设计主张（Design Thesis）

**后台是一张书桌：墨色的框收住导航，暖绢纸面上先摆今天要办的事，数字与列表退到后面。**

- **墨栏**：侧栏是整块暖近黑，和主按钮是**同一支墨**。框架一眼可认，内容区因此可以更安静。
- **暖绢**：内容区是带一点温度的绢色纸面（不是纯白、不是冷灰），列表纸面用暖白，不再用“白纸浮在画布上 + 灰槽 + 白卡”三层套娃。
- **先办事，后看数**：页头摘要句直接说“今天还有几件事”；页面第一块是「今天要办完」**句子队列**，KPI 降为一行没有卡片的数字。
- **刻字标签**：分区标题是小号、疏字距、带一条延伸发丝线的标签——它代替卡片边框做分区。

由此推出：

1. **框架重，内容轻。** 墨只出现在两处：侧栏（框架）与内容区唯一的主按钮。内容区一屏只有一个墨块。
2. **分区靠刻字标签 + 发丝线，不靠卡片。** 只有“能操作的列表”才上纸面（暖白 + 1px 边 + 10 圆角）；概况、问题/建议、前后对比直接排在暖绢上。
3. **句子先于色块。** 待办写成一句话：数量 + 对象 + 金额 + 可否撤销；状态 = 点 + 词 + 时效。
4. **每个有后果的动作都有回执。** 批准 → 墨色回执条 + 倒计时撤销；危险 → 二次确认写清不可逆；无结果 → 空态说明用了哪些条件、怎么放宽。
5. **颜色只给状态。** 绿/橙/红/蓝只在 6px 圆点、文字、2px 线；身份色是墨，不是任何色相。

## 0.1 为什么这样改（Rationale）

| 评分 | 读到的信号 | v8.0 的处理 |
|---|---|---|
| R1 青石 3 分「不喜欢绿色」 | 有色相的身份色是风险 | 身份色继续是墨（无色相） |
| R2 靛墨 4 分 | 换色相解决不了问题 | 不用靛蓝 / 藏青 |
| R3 纸灰·砚墨 5 分 | 安静规则有效：近黑主操作、颜色只给状态、摘要句、决策讲后果 | **规则全部保留** |
| R4 账页 4 分 | 把主张做成戏服（行号、五行节线、页边编号）会扣分 | 不做任何账本符号 |
| **R5 清册 5 分（与 R3 同分，空备注）** | R5 外形几乎就是 R3：同样的白纸浮层、灰槽 KPI 卡、三卡待办。**微调到不了 6 分** | **换外形身份**：墨栏、暖绢、无卡概况、句子队列、回执撤销 |

> 风险与对冲：深色侧栏容易让人想到“老式后台”（藏青 Ant Pro 侧栏）。对冲方式：墨是**暖近黑**（OKLCH h≈70，C≤0.012），不是藏青；当前项只提亮一档，不用彩色高亮；计数用等宽小字，只有异常才红。

## 0.5 Identity：五个签名（换任何库都认得）

1. **墨栏**：侧栏整块 `frame #1E1C19`，文字暖灰 `#B7AFA3`，当前项 `#34302B` + 近白字；分组用刻字标签。侧栏与主按钮同色。
2. **暖绢纸面**：画布 `#F3EFE7`，可操作纸面 `#FFFDF9`（暖白，不用 `#FFF`）。只有两层，不套卡。
3. **刻字标签**：11px / 字距 0.14em / text-3 / 右侧延伸 1px 发丝线；可带一个数字小注（「今天要办完 已办 12 · 剩 3」）。
4. **句子队列**：「今天要办完」是纵向列表，每行 = 状态点 + 时效 | 一句话（数量加粗、金额分级）+ 一行后果 | 动作。最紧急一行左侧 3px 墨线 + 全页唯一主按钮。
5. **回执与撤销**：有后果的批量动作完成后，底部墨色回执条（「已批准 6 笔 · ¥4,218 · 09:59 内可撤销 [撤销]」），对应待办行变成“已完成 · 撤销”。

> 保留（非签名）：金额 `¥` 与小数 0.74em + text-3；状态点 + 词；摘要句；后果按钮写数量与金额。  
> **明确不做**：白纸浮层 + 灰槽 + 白卡三层套娃、KPI 卡片组、行号栏、节线、页边编号、彩色侧栏高亮。

## 1. 三层结构

- **规则**（不变）：§0、§2、§6、§7。
- **角色**（很少变）：§3.1（v8.0 新增 `frame` 角色）。
- **取值**（可替换）：`reference-tokens.css`，须满足 §3.2。

## 2. 判断原则

1. 内容区一屏只有一个墨块（主按钮）；侧栏是框架，不算内容。
2. 先刻字标签与发丝线，再纸面边框，最后阴影（阴影只给浮层）。
3. 有颜色的元素必须能说出代表什么状态。
4. 页面第一块回答“我现在该做什么”，数字其次，明细最后。
5. 有后果的按钮写对象 + 数量 + 金额；完成后给回执；可撤销就给撤销入口。
6. 新人不迷路：主路径、成功出口（回执）、失败出口（空态/确认）都看得见。

## 3. 颜色：角色

### 3.1 角色与参考值（墨栏 · 暖绢）

| 角色 | 用途 | 参考值 |
|---|---|---|
| frame | 侧栏整块 | `#1E1C19`（hover `#2A2723`，当前 `#34302B`） |
| frame-text / text-1 / text-3 | 侧栏文字 / 当前项 / 分组 | `#B7AFA3` / `#F6F2EB` / `#7F776B` |
| canvas | 内容画布（暖绢） | `#F3EFE7` |
| surface | 可操作纸面、弹窗、抽屉 | `#FFFDF9` |
| surface-subtle / hover / selected | 槽 / 悬停 / 选中行、批量条 | `#F8F5EF` / `#F4F0E8` / `#EEE9DF` |
| border / divider / border-strong | 发丝线 / 行分隔 / 控件边 | `#E5DFD3` / `#EDE8DE` / `#D3CBBC` |
| text-1 / 2 / 3 | 正文 / 次 / 说明 | `#1C1A17` / `#4D4840` / `#7A7367` |
| action | 主按钮、当前页、选中框、回执条 | `#1E1C19`（= frame） |
| success / warning / danger / info | 状态点、涨跌 | `#3B7A55` / `#A15C07` / `#B3261E` / `#3F5E8A` |

### 3.2 约束

- frame 与 action 必须是**同一支墨**：HSL S ≤ 10%，L ≤ 13%，色相 30–45°（暖）；对白字 ≥ 14:1。不得为藏青、靛蓝、绿、琥珀、黄。
- 暖绢：OKLCH 色相 70–85，色度 C 0.006–0.016。超过 0.02 会显黄，禁止。禁止冷灰（zinc/slate）。
- surface 不用纯白 `#FFF`，用 L 98–99% 的暖白；与 canvas 明度差 4–6%。
- 状态色只以 ≤6px 圆点、文字、2px 线出现；soft 底只给提示条/危险确认。
- 灰度截图下：框架（墨）/ 画布 / 纸面三档明显可分。

### 3.3 映射到 UI 库

| 角色 | Ant Design 5 | Element Plus | shadcn/ui | MUI |
|---|---|---|---|---|
| frame | `Layout.Sider theme="dark"` + `colorBgContainer` 改墨 | `el-menu` `background-color` | `--sidebar` | `Drawer` paper bg |
| canvas | `colorBgLayout` | `--el-bg-color-page` | `--background` | `palette.background.default` |
| surface | `colorBgContainer` | `--el-bg-color` | `--card` | `palette.background.paper` |
| action | `colorPrimary` + 关 primaryShadow | `--el-color-primary` | `--primary` | `primary.main` + `disableElevation` |
| status | `colorSuccess/...` | `--el-color-*` | 自定义 | `palette.success/...` |
| radius | 6 / 10 / 12 | base 6px | `--radius:0.625rem` | `borderRadius:6` |

须手动补：刻字标签组件、句子队列、无卡数字行、回执条（Ant `message` / Element `ElMessage` 默认样式要改成墨底 + 撤销按钮）。Ant/Element 暗色侧栏默认是藏青——**必须改成墨**，否则直接退回“10 年前后台”。

## 4. 字体排印

- 字族：Inter / SF Pro + PingFang SC / HarmonyOS Sans / Noto Sans CJK；等宽只给单号、手机号、计数、时间。不用衬线。
- 阶梯：11（刻字标签）/ 12 / 13 / 14 / 16 / 24（页标题）/ 30（概况数字）。
- 字重：400 / 550（按钮、当前项）/ 600（数字、小标题）/ 650（页标题）/ 700（句子里的数量）。≥24 字距 −0.025 ~ −0.03em。
- 金额：整数承重；`¥` 与小数 0.74em + text-3。

## 5. 间距、密度、圆角

- 4px 基线；页面内边距 28×36；**区块间距 28**（比 R5 大，因为分区不再靠卡片）。
- 圆角：控件 6、纸面 10、弹窗 12。不用胶囊。
- 行高：两行记录 56（标题 + 等宽编号）；单行 44；紧凑 36/44（`data-density="compact"`）。
- 层级：frame（墨）| canvas（暖绢）→ surface（暖白纸面，1px border）。浮层才有阴影。

## 6. 版式模式

1. **骨架**：左侧墨栏 232px（品牌 / 跳转 ⌘K / 分组导航 / 用户）；右侧暖绢，顶栏透明 + 底部发丝线，放面包屑、视图切换、同步状态。
2. **页头**：标题 → 摘要句（说“今天还有几件事”，数量加粗）→ 口径；次按钮底对齐。主按钮不放页头。
3. **今天要办完（第一块）**：刻字标签 + 纸面上的纵向句子队列。列：状态点+时效 168px | 句子 + 后果 | 动作。最紧急一行：左 3px 墨线 + 唯一主按钮「去审批 N 笔」；其余行只给文字链接。附键盘提示 J/K/↵。
4. **今日概况（第二块）**：刻字标签 + 4 个数字直接排在暖绢上，用 1px 竖发丝线分隔，**不用卡片**。需关注只在标签旁加红字「需关注」，并说明“已在上方待办”。
5. **列表纸面**：标签页 → 筛选（搜索框 + 带标签的下拉）→ 批量条（浅选中底，不用墨，文案含数量/金额/不可恢复）→ 两行记录表格 → 分页。
6. **决策页**：问题 | 建议 两栏散文（刻字标签起头，不进卡）→ 批准后会发生什么（三格前后对比数字行，`37 → 31`）→ 涉及条目（纸面）；右侧摘要纸面：合计、可撤销 / 不可逆、唯一主按钮「批准 N 笔 · ¥X」。
7. **运营出口（全部示范）**：
   - 成功：回执条 + 倒计时撤销；待办行同步变“已完成 · 撤销”。
   - 危险：二次确认，主按钮是红底「确认取消 N 笔」，次按钮写「返回，不取消」。
   - 空态：列出当前生效的条件（虚线小签），给“清空条件”和“只去掉某一个条件”两个出口。

## 7. 组件规则

- 按钮：主（墨底）内容区每屏 ≤1；次（暖白底 + border-strong）；文字按钮。红底只出现在危险确认层。
- 状态：6px 圆点 + 词 + 灰色时效（超时时效变红字）。
- 刻字标签：只做分区标题，不做按钮或标签云；每屏 ≤5 个。
- 焦点：2px 墨 outline，偏移 2px；输入框聚焦 = 墨边 + 3px 墨色淡环。
- 链接：text-1 + 浅下划线，不用蓝色。
- 侧栏计数：等宽小字 text-3；异常才红底白字（一屏 ≤1）。
- 回执条：墨底、近白字、绿色 6px 点、倒计时等宽字、描边「撤销」按钮；10 秒后收起，撤销入口留在待办行与「操作记录」。

## 8. 落地步骤

1. 按 §3.3 填 token，把库的暗色侧栏改成墨；2. 关掉库默认卡片阴影与 KPI 卡片；3. 实现刻字标签组件；4. 页面顺序改为 待办 → 概况 → 列表；5. Tag → 圆点 + 词；6. 补金额分级、后果文案、回执撤销；7. 用 §9 验收。

## 9. 验收清单

- [ ] 侧栏是暖墨，不是藏青/纯黑/彩色；与主按钮同色。
- [ ] 内容区一屏只有一个墨块。
- [ ] 页面第一块是待办句子队列；概况数字不在卡片里。
- [ ] 无三层套娃（画布 → 白纸 → 灰槽 → 白卡）。
- [ ] 灰度下 墨 / 绢 / 纸 三档可分；彩色都能说出状态含义。
- [ ] 成功回执（可撤销）、危险确认、空态三种出口都能看到。

## 10. 不做的事

藏青暗色侧栏、彩色当前项高亮、KPI 卡片组、卡中卡、账本戏服、荧光强调、胶囊按钮、渐变、玻璃拟态、模仿参考作品皮肤。
