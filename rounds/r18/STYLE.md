# Admin UI 设计语言 · v20.0 · Round 18「定向」

> R14–R17 连续 5 分（R17 无备注）。闭眼迭代没有效果；用户在 R11 选配色、R16 选数字字体时参与度最高。R18 改为“选方向”：四个明显不同的方向，内容完全相同，选中的方向在下一轮写成完整规范。

## 共同基础（四个方向都一样）
- 鸢尾（雾紫）主色；颜色只给动作和状态；红色只给异常；黄色只作小点缀；无绿色身份色。
- 只用无衬线：汉字走系统黑体，数字用 Geist（自托管 `fonts/`，unicode-range 只覆盖数字和符号），Geist Mono 只给代码。
- 一屏一个主操作；危险操作写清后果和能否撤销；数字右对齐、表格数字。
- 同一份内容：订单售后（表格）、数据看板、内容审核（列表 + 详情）。

## 四个方向
| id | 名称 | 原则 | 适合 |
|---|---|---|---|
| a | 精简（Linear 式） | 白底、无卡片、1px 发丝线分区；正文 13、表格行 36；控件 28 / 圆角 6；状态只有圆点 + 文字；鸢尾只给操作 | 熟练用户天天用的内部工具 |
| b | 卡片（柔和 SaaS） | 淡紫画布、圆角 18 白卡 + 柔和投影；卡内边距 24、表格行 56；胶囊页签 / 标签 / 按钮；侧栏融入画布 | 面向商家 / 客户的 SaaS |
| c | 深色工作台 | 近黑底 #09090C、3% 白玻璃层卡片；主序列、进度条、选中项带鸢尾辉光，异常带红色辉光；主按钮发光 | 监控、分析、夜间值班 |
| d | 信息密集（AntD Pro / Stripe 式） | 深色侧栏 + 鸢尾实底当前项、灰底、方角 4 卡片 + 浅灰卡头；表格行 34、列竖线 + 斑马纹、12.5 字号；描边标签 | 字段多的企业系统 |

## 实现
- `directions.css`：四段 `[data-direction="a|b|c|d"]` 覆盖 `shell.css`（R17 骨架）。C 方向同时覆盖颜色令牌（深色）。
- `directions.js`：`<html data-direction>`，localStorage `uidl-direction`，`?direction=`；默认 a。反馈提交时自动附 `[当前方向: id]`。
- `directions.html`（主页面）：四张方向卡、原则面板、1440×900 等比缩放的真实页面预览（三个页面可切换）、对比表；「选这个方向」在反馈框预填 `[选定方向: id] 名称`。
- `spec.html`：说明“选中的方向会成为下一轮规范”，并列出五条共同规则（对 / 错）。
- 演示由 `tools/build_r18.py`（复用 `tools/r17_pages.py` 内容）生成。
