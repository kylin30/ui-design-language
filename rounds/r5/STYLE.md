# 后台视觉规范 v7.0（Round 5 ·「清册」）

> **一句话**：与 UI 库无关的后台视觉规范。用 Ant Design、Element Plus、shadcn/ui、MUI 还是手写 CSS，照着做出来都是同一个产品。气质：**冷静、专业、整齐**。
>
> v7.0 回到 R3 已验证的安静结构，去掉 R4「账页」的戏服感，补上运营人机化出口。身份靠层次与任务路径，不靠装饰符号。

---

## 0. 设计主张（Design Thesis）

**后台是一本清册：来核对、比较、做决定，然后离开。**

「清册」不是账本戏服。不追求行号栏、五行一节、页边 01/02/03 或上墨线账条这些“看起来像账”的符号。一屏只保留：今天要办完什么、现在卡在哪里、点下去会发生什么。

由此推出：

1. **层次靠底色，不靠戏服线。** 画布 → 白纸面 → 浅灰槽；能用底色差就不用边框，能用边框就不用阴影。
2. **一屏只有一个“重”的东西。** 近黑主操作或关键数字。颜色只给状态。
3. **句子先于色块。** 标题下一句数字摘要；状态 = 词 + 时效；有后果的按钮写对象、数量、金额与可否撤销。
4. **三行记录统一。** 标题 / 等宽编号 / 补充，表格与审批项同构。
5. **金额分级是格式，不是身份。** `¥` 与小数略降级，整数承重——安静，不当英雄符号。
6. **出口要看得见。** 主路径清晰；危险操作需确认；空态 / 错误 / 加载至少有一种可见示范。

## 0.1 为什么这样改（Rationale）

| 评分 | 读到的信号 | v7.0 的处理 |
|---|---|---|
| R1 青石·朱印 3 分「不喜欢绿色」 | 有色相的身份色是风险 | 主操作继续近黑，身份不靠色相 |
| R2 暖石灰·靛墨 4 分 | 换色（靛蓝）解决不了问题 | 不用靛蓝 / 藏青作身份 |
| **R3 纸灰·砚墨 5 分（最高）** | 三层暖纸、近黑主操作、颜色只给状态、紧字距标题+摘要、三行记录、决策讲后果——有效 | **全部保留为骨架** |
| R4 账页 4 分（回退） | 把主张推成戏服：行号栏、五行节线、页边编号、硬墨账线 | **全部拿掉**；只软保留金额分级 |
| 空备注 | “没点中”，不是要微调 1px | 回到安静身份 + 补运营出口，不堆新符号 |

## 0.5 Identity：五个安静签名（换任何库都认得）

1. **三层暖纸**：`canvas` → `surface`（大圆角浮在画布）→ `surface-subtle` 槽。不用阴影分层。
2. **近黑主操作**：主按钮、选中、分页当前、批量条用 action（HSL S≤8%）。全屏只有它“重”。
3. **颜色只给状态**：≤6px 圆点 / 文字 / 2px 线；soft 底只给提示条。
4. **紧字距无衬线大标题 + 一句数字摘要**：26–28 / 650，字距 −0.025em；关键数字加粗。
5. **三行记录 + 后果按钮**：标题 / mono id / meta；有后果的按钮写「批准 N 笔 · ¥X」，旁注可撤销性。

> 软保留（非签名）：金额 `¥` / 小数 0.78em + text-3。  
> **明确不做**：行号栏、每 5 行节线、页边 01/02/03、上墨线下 rule 的账条 KPI。

## 1. 三层结构

- **规则**（不变）：§0、§2、§6、§7。
- **角色**（很少变）：§3.1。
- **取值**（可替换）：`reference-tokens.css`，须满足 §3.2。

## 2. 判断原则

1. 一屏只有一个最重的东西：近黑主按钮或关键数字。
2. 先底色，再边框，最后阴影（阴影只给浮层）。
3. 有颜色的元素必须能说出代表什么状态。
4. 数字等宽右对齐；金额整数承重，`¥`/小数降级。
5. 有后果的按钮写对象 + 数量 + 金额；旁边写可撤销性。
6. 标题下必须有一句摘要；新人不应迷路（主路径、成功/失败出口可见）。

## 3. 颜色：角色

### 3.1 角色与参考值（暖纸 · 近黑）

| 角色 | 用途 | 参考值 |
|---|---|---|
| canvas | 页面画布、侧栏 | `#F2F1EE` |
| surface | 主纸面、弹窗 | `#FFFFFF` |
| surface-subtle | 槽、表头、KPI 组底 | `#F7F6F3` |
| surface-hover / selected | 悬停 / 选中行 | `#EFEEEA` / `#ECEBE7` |
| border / divider | 发丝线 / 行分隔 | `#E4E2DD` / `#ECEAE6` |
| border-strong | 控件边 | `#D3D0CA` |
| text-1 / 2 / 3 | 正文 / 次 / 说明 | `#171615` / `#4A4743` / `#76726C` |
| action | 主操作、批量条、当前页 | `#1B1A19`（hover `#2E2C2A`） |
| success / warning / danger / info | 状态点、涨跌 | `#2E7D52` / `#A15C07` / `#B3261E` / `#3B5B8C` |
| attention | 风险提示条（白名单） | `#C4320A` |

### 3.2 约束

- action 饱和度 ≤ 8%，与白字对比 ≥ 12:1。不得为绿、藏青、靛蓝、琥珀、黄。
- 中性灰同一暖色相（35–45°，饱和 3–6%）；禁止冷蓝灰（zinc/slate）。
- 状态色只以 ≤6px 圆点、文字、2px 线出现；soft 底只用于提示条。
- 灰度截图下层次仍清楚。

### 3.3 映射到 UI 库

| 角色 | Ant Design 5 | Element Plus | shadcn/ui | MUI |
|---|---|---|---|---|
| canvas | `colorBgLayout` | `--el-bg-color-page` | `--background` | `palette.background.default` |
| surface | `colorBgContainer` | `--el-bg-color` | `--card` | `palette.background.paper` |
| surface-subtle | `colorFillQuaternary` | `--el-fill-color-light` | `--muted` | `palette.grey[50]` |
| action | `colorPrimary` + 关 primaryShadow | `--el-color-primary` | `--primary` | `primary.main` + `disableElevation` |
| status | `colorSuccess/...` | `--el-color-*` | 自定义 | `palette.success/...` |
| radius | 6 / 10 / 14 | base 6px | `--radius:0.625rem` | `borderRadius:6` |

须手动补：三层底色骨架、圆点状态、三行记录、金额分级、后果按钮文案。不补则退回库默认观感。

## 4. 字体排印

- 字族：Inter / SF Pro + PingFang SC / HarmonyOS Sans / Noto Sans CJK；等宽只给编号、单号。不用衬线。
- 阶梯：12 / 13 / 14 / 16 / 22 / 26（页标题）/ 28（KPI）。
- 字重：400 / 550（按钮、选中）/ 600（数字、小标题）/ 650（页标题）。≥22 字距 −0.02 ~ −0.03em。
- 金额：整数 text-1 / 550–600；`¥` 与小数 0.78em + text-3。

## 5. 间距、密度、圆角

- 4px 基线；页面内边距 28×32；区块间距 20。
- 圆角：控件 6、槽/卡 10、主纸面 14、弹窗 12。不用胶囊。
- 行高：三行记录 58；单行 44；紧凑 36（`data-density="compact"`）。
- 层级：canvas → 白纸面（1px border）→ 槽 → 白卡。浮层才有阴影。

## 6. 版式模式

1. **骨架**：侧栏与画布同色、无分隔线；主内容白纸面离窗 8px、圆角 14。
2. **页头**：标题 → 摘要句（关键数加粗）→ 口径；按钮底对齐。
3. **KPI**：4 张白卡放在同一浅灰槽，间距 6；需关注只加小标记，不换大底色。不用上墨线账条。
3b. **今天要办完**：标题下、表格上的主路径槽；最紧急的一格用略强描边 + 唯一主按钮（「去审批 N 笔」）；其余格只给链接。可附键盘提示。
4. **列表**：标签页 + 筛选 → 批量条（墨底，文案含数量/后果）→ 表格（三行记录、圆点状态、金额分级）→ 分页。
5. **决策页**：问题 → 建议 → 批准后会发生什么（前后对比）→ 涉及条目；右侧摘要列可撤销 / 不可逆；主按钮「批准 N 笔 · ¥X」。
6. **运营出口（至少示范一种）**：空态（无结果说明 + 重置筛选）；危险确认（取消订单需二次确认，写清不可逆）。

## 7. 组件规则

- 按钮：主（墨底）每区域 ≤1；次（白底 border-strong）；文字按钮。危险红底只出现在确认层。
- 状态：6px **圆**点 + 词（可加时效灰字；超时变红字）。
- 焦点：2px 墨 outline，偏移 2px。
- 链接：text-1 + 浅下划线，不用蓝色。
- 分段 / 标签：当前项白卡浮起或 2px 墨下划线。
- §7.2 attention 白名单：超时标记、不可撤销警告、通知红点。一屏 ≤2 处。

## 8. 落地步骤

1. 按 §3.3 填 token；2. 关库默认卡片/按钮阴影；3. 实现三层底色；4. Tag→圆点；5. KPI 用浅灰槽+白卡；6. 补金额分级与后果文案；7. 用 §9 验收。

## 9. 验收清单

- [ ] 灰度下层次仍清楚。
- [ ] 一屏彩色都能说出状态含义。
- [ ] 无绿/藏青/靛蓝/琥珀作身份或大面积底色。
- [ ] 无行号栏、无五行节线、无页边编号、无上墨线账条 KPI。
- [ ] 页头有数字摘要；有后果按钮写数量与可撤销性。
- [ ] 可见至少一种空态或危险确认。

## 10. 不做的事

账本戏服（行号/节线/页边号/硬墨账线）、荧光强调、胶囊按钮、每卡不同底色、渐变、玻璃拟态、模仿参考作品皮肤。
