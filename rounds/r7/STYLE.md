# 后台视觉规范 v9.0（Round 7 ·「案头」）

> **一句话**：与 UI 库无关的后台视觉规范。用 Ant Design、Element Plus、shadcn/ui、MUI 还是手写 CSS，照着做出来都是同一个产品。气质：**冷静、专业、整齐**。
>
> v9.0 是 R6（6 分，目前最高）的**精修，不是重来**：墨栏、暖绢、近黑主操作、颜色只给状态全部保留；把“今天要办完”从一张清单推进成**案头**——一件打开、其余等候。

---

## 0. 设计主张（Design Thesis）

**后台是一张案头：一次只摊开一件事，其余在旁边排队；每件事办完都有交代。**

这是我自己对后台的判断，不来自某个参考作品：运营人员的注意力是一条单线程，界面应该替他决定“现在办哪件”，而不是把所有待办平铺给他挑。

1. **一件打开**：最紧急的工作项直接在首页展开——一句话结论、前 4 条明细、后果（可撤销 / 不可逆）、唯一主按钮「批准 6 笔 · ¥4,218」。不用跳页就能办完 80% 的情况；要细看才去「逐笔核对」。
2. **其余等候**：右侧托盘（344px）按紧急度排其余待办，只给文字链接，不给墨块。办完一件，自动提示“下一件”。
3. **办完有交代**：成功 → 回执条 + 倒计时撤销；危险 → 二次确认写清不可逆；无结果 / 加载中 / 出错 → 都有出口，且说明“哪些不受影响”。
4. **节奏统一**：组内 8、组间 16、区块 32；行高全部落在 4px 网格上；字号只用 11/12/13/14/16/20/22 + 数字 28。
5. **墨只出现两处**：侧栏框架，和内容区唯一的主按钮。打开的工作项只用 2px 墨缘标记，不加底色。

## 0.1 为什么这样改（Rationale）

| 评分 | 读到的信号 | v9.0 的处理 |
|---|---|---|
| R1 青石 3「不喜欢绿色」 | 有色相的身份色是风险 | 身份色仍是墨 |
| R2 靛墨 4 | 换色相解决不了问题 | 不用靛蓝/藏青；info 再降饱和为石板灰蓝 |
| R3 纸灰·砚墨 5 / R5 清册 5 | 安静规则有效但外形单调 | 规则保留 |
| R4 账页 4 | 主张做成戏服会扣分 | 不做账本符号 |
| **R6 墨栏·暖绢 6（最高，无备注）** | 外形身份（墨栏 + 暖绢 + 先办事）被认可 | **外形不动**；把“句子队列”升级为“案头”，补齐节奏、字阶和加载/出错出口 |

> 风险：首页展开一件工作项会让首屏更“重”。对冲：打开项只有一个、明细最多 4 行 + “还有 N 笔”，托盘全部降为文字链接。

## 0.5 Identity：五个签名

1. **墨栏**：侧栏 `frame #1E1C19`，与主按钮同一支墨。
2. **暖绢纸面**：画布 `#F3EFE7`，可操作纸面 `#FFFDF9`，只有两层。
3. **刻字标签**：11px / 0.14em / text-3 + 延伸发丝线，可带数字小注（「正在办 1 / 3 · 最紧急」）。
4. **案头**（v9.0 新）：左「正在办」打开项（纸面 + 2px 墨缘 + 20px 结论句 + ≤4 行明细 + 后果条 + 唯一主按钮）；右「等候」托盘（无纸面，上 1px 深线、条目间发丝线，文字链接）。
5. **回执与撤销**：墨色回执条倒计时撤销，打开项变“已完成 · 撤销 · 下一件”。

> **明确不做**：KPI 卡片组、卡中卡、行号/节线、彩色侧栏高亮、托盘里的第二个主按钮。

## 1. 三层结构

- **规则**（不变）：§0、§2、§6、§7。
- **角色**（很少变）：§3.1（v8.0 新增 `frame` 角色）。
- **取值**（可替换）：`reference-tokens.css`，须满足 §3.2。

## 2. 判断原则

1. 内容区一屏只有一个墨块（主按钮）；侧栏是框架，不算内容。
2. 先刻字标签与发丝线，再纸面边框，最后阴影（阴影只给浮层）。
3. 有颜色的元素必须能说出代表什么状态。
4. 页面第一块回答“我现在该做什么”，数字其次，明细最后。
5. 有后果的按钮写对象 + 数量 + 金额；完成后给回执；可撤销就给撤销入口。
6. 新人不迷路：主路径、成功出口（回执）、失败出口（空态/确认）都看得见。

## 3. 颜色：角色

### 3.1 角色与参考值（墨栏 · 暖绢）

| 角色 | 用途 | 参考值 |
|---|---|---|
| frame | 侧栏整块 | `#1E1C19`（hover `#2A2723`，当前 `#34302B`） |
| frame-text / text-1 / text-3 | 侧栏文字 / 当前项 / 分组 | `#B7AFA3` / `#F6F2EB` / `#7F776B` |
| canvas | 内容画布（暖绢） | `#F3EFE7` |
| surface | 可操作纸面、弹窗、抽屉 | `#FFFDF9` |
| surface-subtle / hover / selected | 槽 / 悬停 / 选中行、批量条 | `#F8F5EF` / `#F4F0E8` / `#EEE9DF` |
| border / divider / border-strong | 发丝线 / 行分隔 / 控件边 | `#E5DFD3` / `#EDE8DE` / `#D3CBBC` |
| text-1 / 2 / 3 | 正文 / 次 / 说明 | `#1C1A17` / `#4D4840` / `#7A7367` |
| action | 主按钮、当前页、选中框、回执条 | `#1E1C19`（= frame） |
| success / warning / danger / info | 状态点、涨跌 | `#3B7A55` / `#A15C07` / `#B3261E` / `#4A5A70` |

### 3.2 约束

- frame 与 action 必须是**同一支墨**：HSL S ≤ 10%，L ≤ 13%，色相 30–45°（暖）；对白字 ≥ 14:1。不得为藏青、靛蓝、绿、琥珀、黄。
- 暖绢：OKLCH 色相 70–85，色度 C 0.006–0.016。超过 0.02 会显黄，禁止。禁止冷灰（zinc/slate）。
- surface 不用纯白 `#FFF`，用 L 98–99% 的暖白；与 canvas 明度差 4–6%。
- 状态色只以 ≤6px 圆点、文字、2px 线出现；soft 底只给提示条/危险确认。
- 灰度截图下：框架（墨）/ 画布 / 纸面三档明显可分。

## 4. 字体排印

- 字族：Inter / SF Pro + PingFang SC / HarmonyOS Sans / Noto Sans CJK；等宽只给单号、手机号、计数、时间。不用衬线。
- 阶梯：11（刻字标签）/ 12 / 13 / 14 / 16 / 20（打开项结论句）/ 22（页标题）/ 28（概况数字）。
- 行高落 4px 网格：12/16、13/20、14/22、16/24、20/28、22/28、28/32。
- 字重：400 / 550（按钮、当前项）/ 600（数字、小标题）/ 650（页标题）/ 700（句子里的数量）。≥24 字距 −0.025 ~ −0.03em。
- 金额：整数承重；`¥` 与小数 0.74em + text-3。

## 5. 间距、密度、圆角

- 4px 基线；页面内边距 28×40；**节奏 8 / 16 / 32**：组内 8、组间 16、区块 32。案头左右间距 24。
- 圆角：控件 6、纸面 10、弹窗 12。不用胶囊。
- 行高：两行记录 56（标题 + 等宽编号）；单行 44；紧凑 36/44（`data-density="compact"`）。
- 层级：frame（墨）| canvas（暖绢）→ surface（暖白纸面，1px border）。浮层才有阴影。

## 6. 版式模式

1. **骨架**：左侧墨栏 232px（品牌 / 跳转 ⌘K / 分组导航 / 用户）；右侧暖绢，顶栏透明 + 底部发丝线，放面包屑、视图切换、同步状态。
2. **页头**：标题 → 摘要句（说“今天还有几件事”，数量加粗）→ 口径；次按钮底对齐。主按钮不放页头。
3. **案头（第一块，v9.0 取代句子队列）**：左「正在办」打开项 + 右 344px「等候」托盘；以下旧规则仅用于托盘条目——：刻字标签 + 纸面上的纵向句子队列。列：状态点+时效 168px | 句子 + 后果 | 动作。最紧急一行：左 3px 墨线 + 唯一主按钮「去审批 N 笔」；其余行只给文字链接。附键盘提示 J/K/↵。
4. **今日概况（第二块）**：刻字标签 + 4 个数字直接排在暖绢上，用 1px 竖发丝线分隔，**不用卡片**。需关注只在标签旁加红字「需关注」，并说明“已在上方待办”。
5. **列表纸面**：标签页 → 筛选（搜索框 + 带标签的下拉）→ 批量条（浅选中底，不用墨，文案含数量/金额/不可恢复）→ 两行记录表格 → 分页。
6. **决策页**：问题 | 建议 两栏散文（刻字标签起头，不进卡）→ 批准后会发生什么（三格前后对比数字行，`37 → 31`）→ 涉及条目（纸面）；右侧摘要纸面：合计、可撤销 / 不可逆、唯一主按钮「批准 N 笔 · ¥X」。
7. **运营出口（全部示范）**：
   - 成功：回执条 + 倒计时撤销；待办行同步变“已完成 · 撤销”。
   - 危险：二次确认，主按钮是红底「确认取消 N 笔」，次按钮写「返回，不取消」。
   - 空态：列出当前生效的条件（虚线小签），给“清空条件”和“只去掉某一个条件”两个出口。
   - 加载（v9.0）：只在出问题的区域放骨架行（与真实行同高 56），页脚写“正在加载…”；不整页转圈。
   - 出错（v9.0）：红点 + 一句标题“X 没有加载出来” + 说明哪些不受影响 + 「重试」「复制错误编号」+ 等宽错误编号与时间。不用红色大块背景。

## 7. 组件规则

- 按钮：主（墨底）内容区每屏 ≤1；次（暖白底 + border-strong）；文字按钮。红底只出现在危险确认层。
- 状态：6px 圆点 + 词 + 灰色时效（超时时效变红字）。
- 刻字标签：只做分区标题，不做按钮或标签云；每屏 ≤5 个。
- 焦点：2px 墨 outline，偏移 2px；输入框聚焦 = 墨边 + 3px 墨色淡环。
- 链接：text-1 + 浅下划线，不用蓝色。
- 侧栏计数：等宽小字 text-3；异常才红底白字（一屏 ≤1）。
- 回执条：墨底、近白字、绿色 6px 点、倒计时等宽字、描边「撤销」按钮；10 秒后收起，撤销入口留在待办行与「操作记录」。

## 8. 落地步骤

1. 按 §3.3 填 token，把库的暗色侧栏改成墨；2. 关掉库默认卡片阴影与 KPI 卡片；3. 实现刻字标签组件；4. 页面顺序改为 待办 → 概况 → 列表；5. Tag → 圆点 + 词；6. 补金额分级、后果文案、回执撤销；7. 用 §9 验收。

## 9. 验收清单

- [ ] 侧栏是暖墨，不是藏青/纯黑/彩色；与主按钮同色。
- [ ] 内容区一屏只有一个墨块。
- [ ] 页面第一块是案头：只有一件打开，托盘里没有墨块；概况数字不在卡片里。
- [ ] 加载与出错只影响出问题的区域，并写明哪些不受影响。
- [ ] 无三层套娃（画布 → 白纸 → 灰槽 → 白卡）。
- [ ] 灰度下 墨 / 绢 / 纸 三档可分；彩色都能说出状态含义。
- [ ] 成功回执（可撤销）、危险确认、空态三种出口都能看到。

## 10. 不做的事

藏青暗色侧栏、彩色当前项高亮、KPI 卡片组、卡中卡、账本戏服、荧光强调、胶囊按钮、渐变、玻璃拟态、模仿参考作品皮肤。
