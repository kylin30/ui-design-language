# 后台视觉规范 v6.0（Round 4 ·「账页」）

> **一句话**：与 UI 库无关的后台视觉规范。用 Ant Design、Element Plus、shadcn/ui、MUI 还是手写 CSS，照着做出来都是同一个产品。气质：**冷静、专业、整齐**。
>
> v6.0 不再从任何参考作品“借皮肤”，先写清楚**我们相信后台是什么**（§0 设计主张），所有视觉都从主张推出来。

---

## 0. 设计主张（Design Thesis）

**后台不是展示页，是一本账。** 用户来这里核对、比较、做决定，然后离开。所以：

1. **对齐比装饰重要。** 眼睛沿着“列”走，而不是沿着“卡片”走。页面上所有信息都落在同一套栏线上：摘要账条、筛选、表格、合计行共用列边。能用一条线说清的关系，不用一个框。
2. **数字是主角，单位是配角。** 金额的整数部分是信息，`¥` 和 `.00` 是格式。格式降一级（0.78 倍、三级灰），整数保持重量。所有数字等宽、右对齐、小数点对齐。
3. **节奏帮人数行。** 人一眼只能稳稳数 5 个。表格每 5 行一条稍深的“节线”，左侧有行号栏，长列表不会看串行。
4. **状态是一句话，不是一个色块。** 状态 = 词 + 时效（“待发货 · 超时 2 小时”）。颜色只是 6px 方点，真正的信息在字和时间上。
5. **有后果的事要先讲账。** 决策页按“问题 → 建议 → 账面变化（现在 → 批准后）→ 涉及条目”排，按钮上写数量和金额，旁边写可撤销 / 不可逆。
6. **密度是用户的选择，不是设计师的。** 宽松 / 标准 / 紧凑三档，只改行高和内边距，不改字号与层级。

## 0.1 签名元素（换任何库都认得出来）

| 签名 | 规则 | 来自哪条主张 |
|---|---|---|
| ① 数字分级 | 货币符号与小数 = 0.78em + text-3；整数 = text-1 / 550–600；KPI 32px −0.03em | 主张 2 |
| ② 行号栏 + 五行一节 | 表格最左 44px 等宽行号栏（disabled 色、右侧发丝线）；每第 5 行底线用 `rule` 色；选中行行号变墨色并加 2px 墨线 | 主张 3 |
| ③ 账线 | 主要数据区上方一条 **1px 墨线**（text-1），下方一条 `rule` 线；摘要账条、表头、合计行、决策页步骤都用它。不用卡片包 KPI | 主张 1 |
| ④ 页边编号 | 决策 / 表单长页用 01 02 03 等宽小号编号作左页边，正文缩进 44px，与行号栏同宽 | 主张 1、5 |

## 0.2 为什么这样改（Rationale）

| 评分 | 读到的信号 | v6.0 的处理 |
|---|---|---|
| R1 青石 3 分“不喜欢绿色” | 有色相的身份色都是风险 | 身份不靠颜色；主操作近黑铅墨 |
| R2 靛墨 4 分 | 换色不解决问题 | 不再换色 |
| R3 纸灰·砚墨 5 分 | 结构、克制、底色分层、决策页有效 | 全部保留；把“分层”从**底色**推进到**对齐与节奏** |
| 用户：“要有自己的理解，不要模仿” | 需要一个能自圆其说的主张 | 写下 §0，视觉只从主张推导；参考作品只用来验证主张，不取其外观 |

## 1. 三层结构

- **规则**（不变）：§0、§2、§6、§7。
- **角色**（很少变）：§3.1 角色名。
- **取值**（可替换）：`reference-tokens.css`，替换后须满足 §3.2。

## 2. 判断原则

1. 一屏只有一个最重的东西：墨色主按钮或关键数字。
2. 先用对齐，再用线，再用底色，最后才用阴影（阴影只给浮层）。
3. 有颜色的元素必须能说出代表什么状态。
4. 数字等宽右对齐；金额必须有合计行。
5. 有后果的按钮写对象 + 数量 + 金额；旁边写可撤销性。
6. 标题下必须有一句“用句子写的摘要”，关键数字加粗。

## 3. 颜色：角色

### 3.1 角色与参考值（铅灰 · 铅墨）

| 角色 | 用途 | 参考值 |
|---|---|---|
| canvas | 页面画布、侧栏 | `#F3F2EF` |
| surface | 主纸面 | `#FFFFFF` |
| surface-subtle | 决策摘要、搜索框 | `#F8F7F5` |
| surface-selected | 选中行 | `#F1EFEB` |
| divider | 普通行线 | `#EEECE8` |
| **rule** | 节线、表头下、分组线 | `#D9D6D0` |
| ink-rule | 账线（=text-1） | `#1C1B19` |
| border-strong | 控件边 | `#D2CFC8` |
| text-1 / 2 / 3 / disabled | 正文 / 次 / 说明 / 行号 | `#1C1B19` / `#4B4843` / `#7A766F` / `#AEAAA2` |
| action | 主操作、当前筛选、批量条 | `#1F1E1C` |
| success / warning / danger / info | 状态方点、涨跌字 | `#2F7A50` / `#A35B0A` / `#B4291F` / `#456086` |

### 3.2 约束

- action 饱和度 ≤ 8%，与白字对比 ≥ 12:1。不得为绿、藏青、靛蓝、琥珀、黄。
- 中性灰同一暖色相（35–45°，饱和 3–6%）；禁止冷蓝灰（zinc/slate 特征）。
- 状态色只以 ≤ 6px 方点、文字、2px 线出现；soft 底只用于提示条。
- 灰度截图下层次仍清楚。

### 3.3 映射到 UI 库

| 角色 | Ant Design 5 | Element Plus | shadcn/ui | MUI |
|---|---|---|---|---|
| canvas | `colorBgLayout` | `--el-bg-color-page` | `--background` | `palette.background.default` |
| surface | `colorBgContainer` | `--el-bg-color` | `--card` | `palette.background.paper` |
| surface-selected | Table `rowSelectedBg` | `--el-table-current-row-bg-color` | 行 `data-[state=selected]:bg-*` | `TableRow.selected` 样式覆盖 |
| divider / rule | `colorSplit` / Table `borderColor` | `--el-table-border-color` / 自定义 `--rule` | `--border` / 自定义 `--rule` | `palette.divider` / 自定义 |
| text-1/2/3 | `colorText/Secondary/Tertiary` | `--el-text-color-primary/regular/secondary` | `--foreground` / `--muted-foreground` | `text.primary/secondary` |
| action | `colorPrimary` + `Button.primaryShadow:none` | `--el-color-primary` | `--primary` | `primary.main` + `disableElevation` |
| status | `colorSuccess/Warning/Error/Info` | `--el-color-*` | 自定义 `--success` 等 | `palette.success/...` |
| radius | `borderRadius:4`, `borderRadiusLG:8` | `--el-border-radius-base:4px` | `--radius:0.5rem` | `shape.borderRadius:4` |
| 行高 | Table `cellPaddingBlock` 使行高 48 | `--el-table-row-height` 自定义 | `TableCell h-12` | `TableCell size` + `sx` |

签名在任何库都要**手动补**：① 金额单元格用 render/slot 输出 `<s>¥</s>整数<i>.00</i>`；② 首列加行号列、`tr:nth-child(5n)` 底线改 `rule`；③ 表头下边框改 1px text-1、合计行上边框同；④ 长决策页用 44px 页边编号。不补签名，任何库都会退回它自己的默认观感。

## 4. 字体排印

- 字族：Inter / SF Pro + PingFang SC / HarmonyOS Sans / Noto Sans CJK；等宽 JetBrains Mono / IBM Plex Mono，只给编号、行号、页边编号。不用衬线。
- 阶梯：11（行号）/ 12 / 13.5（表格正文）/ 14 / 15（摘要句）/ 17（决策要点）/ 28（页标题）/ 32（关键数字）。
- 字重：400 / 550（按钮、当前项、金额）/ 600（数字、小标题）/ 650（页标题）。≥ 28 字距 −0.025 ~ −0.03em。
- 数字分级见 §0.1 ①。

## 5. 网格、节奏、密度、圆角

- 4px 基线；页面内边距 28 × 32；区块间距 24。
- 栏：行号栏固定 44px，是全站的“页边”；决策页正文从 44px 起排。
- 行高：宽松 60 / 标准 48 / 紧凑 36（`data-density`）。每 5 行一条 rule。
- 圆角：控件 4、浮层 8、主纸面 12。不用胶囊。
- 层级：canvas → 白纸面（1px border）→ 线。浮层才有阴影。

## 6. 版式模式

1. **骨架**：侧栏与画布同色；主内容是一张白纸面，离窗 8px。
2. **页头**：28px 标题 → 15px 摘要句（关键数加粗）→ 12px 口径与更新时间；按钮底对齐。
3. **摘要账条**：4 格，上墨线下 rule，格间发丝竖线，无卡片；需关注只在格标题右侧写红字“6 超时”。
4. **列表**：筛选 chip（当前项墨底）+ 右侧筛选与密度切换 → 批量条（墨底，按钮写数量）→ 表格（行号栏、两行记录、金额分级右对齐、状态 = 方点 + 词 + 时效）→ 合计行。
5. **决策页**：页边编号 01 问题 / 02 建议 / 03 账面变化（项目 | 现在 → 批准后 | 变化）/ 04 涉及条目 + 合计；右侧固定摘要：大金额 → 明细 → 可撤销 / 不可逆 / 不通知 → 主按钮“批准 6 笔退款 · ¥4,218”。

## 7. 组件规则

- 按钮：主（墨底）每区域 ≤ 1；次（白底 border-strong）；文字按钮。危险操作只在确认层出现红底。
- 状态：6px **方**点 + 词 + 时效（灰小字；超时变红字）。
- 链接：text-1/2 + 浅下划线，不用蓝。
- 焦点：2px 墨色 outline，偏移 2px。
- 红色白名单：超时、不可逆、通知计数。一屏 ≤ 3 处。

## 8. 落地步骤

1. 按 §3.3 填 token，关掉库默认阴影；2. 加行号列与五行节线；3. 金额渲染器做数字分级 + 合计行；4. 表头 / 摘要账条加墨线；5. 状态改方点 + 时效；6. §9 验收。
