# Admin UI 设计语言 · v16.0 · Round 14「展卷」

> R13 连续 6 分，备注“暂时没有什么突破”。研究（rounds/r14/research.md）结论：不是规则错，是**呈现太平**——字阶反差小、没有纵深、图表和细节单薄、没有主图卡和动效。R14 保留全部核心约束（鸢尾默认 + 6 主题、颜色只给动作和状态、任务流优先、黄色只作小点缀），做一次视觉跃升。

## R14 新增
1. **四层字阶**：展示层用宋体（--font-display，48/56、36/44），数字用细无衬线大号（--fs-figure-xl 56、lg 32），正文 14，眉标 11px 等宽大写 + .14em 字距。反差要大。
2. **三层纵深**：页面底色 → 浮卡（--radius-card 14、--shadow-card）→ 浮层（后果条、提示、Toast）。卡片之间用留白分隔，不用边框。
3. **规则 14 · 每页一张主图卡**：首屏第一张卡回答“现在最要紧的是什么”，用一句宋体结论或一个大数字，右侧放一个图形证据（环、堆叠条、点阵）。
4. **图表升级**：面积图带渐变、目标线、异常红点和悬停提示；环形进度、点阵、直方图；所有图形入场时有生长动画，并且尊重 prefers-reduced-motion。
5. **骨架**：224px 浮动深色侧栏（圆角 16）+ 顶栏药丸式演示切换 + 底部浮动后果条。
6. **token ⑤**：--font-display、--font-figure、--fs-*、--radius-card/shell、--shadow-card(-hover)、--motion-*、--ease-out。

# 后台设计语言 v15.1（Round 13 ·「流转台」）

> R8–R12 连续 5 轮 6 分，细节打磨已推不动。本轮换掉骨架和信息层级：**后台是一条队列，一次办完一件。** 鸢尾默认 + 6 个主题、主题切换、规矩/角色/取值/映射结构保留。

## 主张
1. **流转**：界面按办事的顺序排：左边队列，右边当前事，底部是后果条和按钮。办完自动接下一件（J/K 切换，E 执行，Z 撤销）。
2. **字形**：阶段看形状（○ 待办 / ◐ 进行中 / ● 完成 / ◆ 异常），颜色只留给异常。
3. **一张纸**：深色框架（52px 图标轨）里嵌一整张圆角工作纸，纸上只有发丝线和留白，没有卡片墙。

### 本轮精修（v15.0）
- 主按钮：极浅的自上而下高光 + 1px 内高光 + 带紫调的落地影；按下时去掉高光、换成按下色。
- 焦点：2px 主色实线 + 5px 主色柔光环（focus-ring），键盘路径更清楚。
- 状态点：加 3px 同色 14% 的光晕，小但更易辨认。
- 纸面纵深与浮层投影改为紫调阴影（rgba(32,20,70,…)），和鸢尾同一温度。
- 侧栏当前项：底色里混入一点主色，左缘刻线也偏主色。
- 发丝线、选中底再降一档饱和（#E9E6F1 / #F0EDFD），表格选中行加 2px 主色左缘。
- 链接下划线用主色 35% 透明度；选中文字用选中底色；换主题时颜色 0.2s 过渡。

## 主题体系
- 写法：`<html data-theme="lake">`；不写 = 鸢尾。`reference-tokens.css` 结构：① 角色层 ② 默认（:root）③ 每个主题只写和默认不同的值 ④ 不随主题变化的尺寸/字号/间距。
- **主题可以改**：角色的取值（画布、纸面、线、三级文字、侧栏、主色及其状态）、状态色的具体色相、纸面纵深、图表序列、侧栏深浅、深色模式。
- **主题不能改**：12（+1）条规矩、结构与尺寸、状态语义（异常永远红色系、6px 点 + 文字）、对比度底线。
- 组件库落地：AntD 用一份 base token + 每个主题的差异对象喂给 ConfigProvider（深色主题加 darkAlgorithm）；Element Plus 在 `html[data-theme=x]` 下覆盖 `--el-*`；shadcn 在 `[data-theme=x]` 下覆盖 `--primary/--background/...`（next-themes attribute="data-theme"）；MUI 用 createTheme(base, 差异) 生成每个主题。
- 评审页：右上角页头「主题」菜单切换，支持 `?theme=` 与 localStorage。

## 第 13 条 · 主题只换取值
换主题后，人仍靠同样的位置和颜色含义找到“下一步”和“出问题的地方”。主题只覆盖 `--color-*`。

## 第一层 · 12 条规矩（长期不变）
| # | 规矩 | 为什么 | 令牌 |
|---|---|---|---|
| 01 | 一屏一个主操作 | 主色按钮是“下一步”的唯一答案 | --role-action |
| 02 | 颜色只表示状态（6px 点 + 文字） | 装饰色会淹没真正的异常 | --role-success…danger |
| 03 | 先结论，后明细 | 第一行告诉人有什么事、多严重 | 标题下摘要 |
| 04 | 数字右对齐、等宽 | 便于纵向比较 | tabular-nums |
| 05 | 发丝线，不画框 | 线只分隔，不装饰 | --color-hairline |
| 06 | 分层靠底色，不靠投影 | 画布 → 纸面两层；投影只给浮层 | --shadow-pop |
| 07 | 间距只有 8 / 16 / 32（+4 / 40） | 间距表达关系 | --rhythm-* |
| 08 | 字号 7 档，靠字重强调 | 档位少层级才清楚 | --fs-* |
| 09 | 危险操作写清后果，按钮写动作+数量 | “确定吗”什么也没说 | --role-danger |
| 10 | 空 / 加载 / 出错都有出口 | 不留死胡同 | — |
| 11 | 表格行高 44（紧凑 36），主次两级 | 密而不挤 | --row-h-* |
| 12 | 焦点 2px 钴蓝实线，偏移 2px | 键盘用户要知道在哪 | --focus-outline |

## 第二层 · 角色
框架、画布、纸面、主/次/轻/危险操作、四种状态、三级文字、数字、分区标签、焦点。组件只引用 `--role-*`，见 reference-tokens.css ① 与 spec.html#roles。

## 第三层 · 取值（可整套替换）
见 reference-tokens.css ②。替换条件：主操作对白字 ≥ 4.5:1（AA）；状态色不做大面积底色；仍满足 12 条规矩。
