# Admin UI 设计语言 · v21.0 · Round 19「素线」

> R18 5 分，选定方向 A「精简」（`[选定方向: a] 精简`）。R19 把它写成完整语言：骨架、组件、16 条规则、角色、取值、组件库映射、主题、六个演示。目标是 Linear 级的精简质感。

## 原则
1. **纸**：白底，没有卡片；区块用 1px 发丝线 + 留白分隔。投影只给浮起的东西（命令面板、菜单、Toast）。
2. **单色**：界面黑白灰；鸢尾只给主操作、选中、焦点。状态 = 6px 圆点 + 文字，无底色；只有异常文字变红。黄色只作小圆点。
3. **小而准**：正文 / 表格 13，辅助 12，页标题 18，KPI 22/500；层级靠字重和三级灰。对齐即结构：同一条左边线，数字列右对齐到同一条线。
4. **键盘**：⌘K / `/` 打开命令面板；G + 字母跳页；J 下一件、E 办完、Z 撤销、C 新建；按钮上直接显示键帽。
5. **克制的状态反馈**：悬停 4% 灰；选中 6% 鸢尾 + 2px 鸢尾左线；页签当前项是黑色下划线（不是主色）。

## 组件
- 按钮：主（鸢尾实底 + 1px 内高光）、次（发丝边）、轻、危险（红边）、禁用；28 高；主操作带键帽。
- 输入 / 下拉：28 高、发丝边；聚焦鸢尾边 + 3px 14% 光环；出错红边 + 12 说明。
- 页签：黑色下划线；分段控件 22 高。
- 表格：表头无底色，12/500 灰；行 36；数字 Geist、右对齐；勾选行 6% 鸢尾。
- 命令面板：560 宽、圆角 10、浮层投影；分组、键帽、↑↓↵Esc 提示、无结果状态。
- 空状态：图标块 + 原因 + 建议 + 次按钮；加载：骨架条。
- 图表：只用灰和鸢尾——本期鸢尾实线 + 14% 渐隐填充，对比期灰虚线，目标线灰点线，异常点红；悬停读数。

## 字体
汉字走系统黑体；数字 Geist（自托管 `fonts/`，unicode-range 只覆盖数字和符号）；Geist Mono 只给代码。不用衬线。

## 主题
鸢尾默认；cobalt / lake / graphite / daylight / coral / midnight 为主题，只覆盖取值，`data-theme`、`?theme=`、localStorage `uidl-theme`。midnight 为深色。

## 文件
`shell.css`（骨架）+ `minimal.css`（素线）+ `reference-tokens.css`（取值 ⑥）；演示由 `tools/build_r19.py` 生成，规范由 `tools/build_r19_spec.py` 生成。
