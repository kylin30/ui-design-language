# R27「素净」· 视觉噪音审计

R26「平整」58 / 100（和 R25 一样），批注：「总是有不干净的感觉」，在 demo-crm.html 提交。没有指出某一个组件，所以这一轮先把“不干净”数出来。

## 方法
- 1440×900、iris、反馈面板收起，只看首屏（滚动前看到的部分）。
- `tools/noise.js`：遍历首屏所有可见元素（不含反馈面板、⌘K、Toast、菜单、提示），数边框边、线色、填色块、面板里的底色块、文字颜色、字号、字重、文字样式（字号 × 字重）、图标及尺寸、标签、徽标、装饰（迷你线、分段条、进度条、头像、图表、时间线）、圆角种类、截断、行首左边缘（文字从所在块的内边距起排、同一行前面没有别的内容时的 x）。
- `tools/noise_lines.js`：把同一坐标上首尾相接的边框段合并成“一条看得见的线”，不含 24px 以下的小件（复选框、圆点）。
- `tools/imgnoise.py`：截图里既不是面板白也不是画布灰的像素占比（带色面积），以及长线条数。参照截图同样处理。
- 线色：R26 的面板外框是 `box-shadow` 环（文字色 8%），不算在 border 颜色里，表里 R26 的线色已经加上这 1 种。选中页签的下划线、复选框边框不计。
- 原始数据：`clean/noise.json`。

## 结论
不干净不是哪个组件坏了，而是 **R22–R26 每轮叠一层样式**：`reference-tokens`（20.7 KB）→ `shell` → `minimal` → `group` → `r24` → `material` → `flat`，再加每页内联 `<style>`，同一个属性（如 `.row` 内边距、`.kpi .v` 字号、`.ch` 高度、`.tag`）被覆盖 3–6 次。留下的结果：

1. **字号太多**：每屏 10–11 个（12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15 / 16–18 / 26 / 28），相差 0.5–1px 的字号看不出层级，只显得不齐。
2. **假字重**：450（minimal.css）和 700（r24.css）不是 Geist 的真实字重，浏览器合成，笔画粗细不一。
3. **面板里套色块**：每屏 0–9 块浅灰（组标题底条、键值井、表头底、页脚底、筛选条、帖子底），每块都是多出来的一层面。
4. **线太多、线色不一**：可见线条 42–60 条，3–5 种线色（面板环、面板内分隔、表头线、行线、内联 `border-top`）。
5. **装饰重复数字**：KPI 里的迷你趋势线、分段条、进度条，标题前的字头像块，联系人和作者的字头像。
6. **次要文字太黑**：三级灰 #111114 / #3E3E46 / #5C5C66（L* 5 / 26 / 39），说明行几乎和标题一样黑，面板读起来是一片深灰。
7. **红色重复**：同一指标块数字红、说明红；订单表状态红、等待天数也红。
8. **间距和边缘**：面板间距 16 / 20 / 21 混用；面板内左边缘 16 / 20 / 21 / 24 混用；圆角 7–12 种。
9. 没有截断（每页 0）。

### 逐页批注（R26）
**客户管理**
- **页头**：标题前 48px 的“鲸”字头像块（第 3 种面、第 3 种圆角 12）、标题旁带点标签。
- **KPI**：健康分下有进度条（meter，第 2 种红）；健康分、说明、活跃席位 3 处红。
- **动态面板**：页签下的图表小标题是内联 13/500 + 12px 元信息（第 11 个字号）；时间线上面再画一条 `border-top` 内联线；时间线有圆点 + 竖线。

## 改动
1. **一份样式表**：7 个文件 + 页内 `<style>` 合成 `app.css`（27 KB，一套令牌）；演示页只加载 `app.css`、`theme-switcher.css` 和反馈面板。主题切换器、反馈面板用到的旧令牌名在 `app.css` 末尾映射到新令牌。
2. **两种面、一种线**：面板 = 白 + 1px `#E6E6EB`，无投影；组标题、键值区、表头、页脚、筛选条、帖子全部去掉底色；列表行、KPI 格、面板内分区去掉线，用 24–32px 留白；时间线去掉圆点和竖线。
3. **三级灰拉开**：#17171C / #55555F / #73737E（L* 8 / 37 / 49）。
4. **字号五档、字重三档**：28 / 24 / 16 / 14 / 13（+12 坐标轴、快捷键），400 / 500 / 600；内联 13/500 小标题统一成 `.sh`（14/500）。
5. **8 的倍数、一条左边缘**：页边、面板内边距、面板间距都是 24，分区 32；明细表首末列贴齐内边距；圆角收成 8 / 12（另有快捷键 4、主题色块 3、分段控件内块 6、条形图 1、圆点）。
6. **删装饰**：KPI 迷你线、分段条、进度条，标题前“鲸”字块，联系人、作者头像。
7. **红色只出现一次**：数字红了说明就灰；活跃席位不标红；订单表等待天数不标红；表格里的跌幅不标红。
8. **单选**：去掉三个单选外框，只留原生圆点。
9. 业务数据、文案、交互（⌘K、J / E / Z、批量、撤销、筛选）不变；`tools/build_r27.py` 从 R26 页面生成，JS 里删掉的元素都加了空值保护。
