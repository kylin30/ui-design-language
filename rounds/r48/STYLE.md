- **动效（抬 7.5）**：堆叠柱自底 `scaleY` 升起（错开 40ms）；轨内 `.dist` 自左展开；KPI 卡微错开；spark 描线一次；入场收敛为 6px / 200ms。全部包在 `prefers-reduced-motion` 内。
- **继承**：填充状态、青–石板系列方向、g-wide sticky rail、reduced-motion、surface 柱描边。

## R44 状态规则（继承）
- 常规状态只用填充样式：**已结束 = 灰实底**（悬停色底 + 文字 2）、**进行中 = 蓝色浅底**（数据蓝 12% 浅底 + 数据蓝字，不用实底，保证异常最醒目）、**待处理 = 白底描边**（面板底 + 1px 描边）。高 20，圆角 4，12/500。
- **只有异常用色**：红色 1px 虚线边 + 红 12% 浅底 + 红色图标文字。
- 状态徽标（胶囊）= 状态色 12% 浅底 + 同色图标和文字。浅色：正常 #E5F2EC、注意 #FAF1E2、异常 #FAE8E8、信息 #E6EBFA、中性 #F1F2F4；深色（同色相、低明度）：#132A1F / #2E2412 / #351B1B / #1A2645 / #262B35。

- 单位（万、分）：正文字体，0.6em，文字 2 色，左距 2px，数字与单位之间不留空格。
- 动效系统：悬停 120ms，按下 60ms（下移 1px）；进入、切换、抽屉 200ms（淡入 + 上浮 4px / 右滑 8px，抽屉内容延迟 80ms）；列表切换时详情面板重放进入动画；标签切换时表格先显示 360ms 骨架屏；骨架扫光 1200ms 循环只用于加载；prefers-reduced-motion 下全部降到 1ms。
- 布局：.main 最大 1440 居中；≥1520 时侧栏详情列加宽到 400 / 440。
- 状态胶囊（彩色徽标）只用于告警严重度和指标，不用于业务流程状态。
- 表格：数值 / 状态列收窄（1%），操作列 40 宽，富余宽度留给文字列。

# （以下为 R43）后台设计语言 v45.0 · Round 43「精修」

> R43 在 R42 的从零代码和 lint 上修正 60 分的原因：配色无个性、层级平、面板浮不起来、运维页稀疏。下文 token 已更新；R42 原文保留结构。

## R43 变更
- **品牌：墨蓝 #18203A**（主按钮、选中导航、步骤、焦点环、选中行指示条）；**数据蓝 #2E5BD8** 只给链接、信息状态、图表主系列。深色主题主按钮反转为浅色胶囊 #E4E8F2 + 墨字。理由：Xiang 先要黑白金红、后认可海军蓝 + 冷灰；墨蓝兼顾「黑」的克制与「蓝」的冷静，不是默认的钴蓝。
- **画布加深**：#E9ECF1（R42 #E9ECF1），面板 e1 投影加重，白面板在画布上明显浮起。
- **页头**：标题 40/48 · 600（新增字号 40），右侧加 1–2 个关键数字（28 / 500，竖线分隔）。
- **动效**：面板入场 200ms 上浮 4px，依次延迟 40ms；图表主线 480ms 描线；按下位移 1px；尊重 prefers-reduced-motion。
- **运维页加密度**：按严重度分组、每条带迷你走势、筛选条、详情加元信息、分布条和处理经过。


从零重写，不继承 r30–r41 的任何 CSS，不参照外部案例。先定规范，再建组件，再做页面；页面只许使用本文的 token 与组件，lint 脚本（tools/lint_r42.js）强制检查。

## 原则
1. **面板分组**：浅色画布上用看得见的白面板分组，一个对象一块面板。
2. **少即是规则**：间距、字号、圆角、颜色、投影都是封闭集合，集合外的值一律视为缺陷。
3. **扁平操作**：按钮无投影、无渐变；层次靠颜色和描边。
4. **数字可读**：数字用 Geist + 等宽数字，数值列右对齐。
5. **状态不靠颜色单独表达**：每个状态 = 图标 + 文字 + 色。
6. **动效克制**：只有 120ms / 200ms 两档，只做颜色、透明度、位移 ≤ 4px。
7. **标题层级清楚**：页标题 28 / 600，面板标题 14 / 600，正文 14 / 400。
8. **宽松但不稀疏**：表格行 44，面板内边距 16，面板间距 16，页边距 32。

`0 4 8 12 16 20 24 32 40 48`（`--s1`…`--s12`）。另允许 1px 描边与 2px 焦点环，不作为间距。

### 圆角与嵌套规则
`4 8 16 999(胶囊) 50%(圆)`（四档）。**嵌套规则：里层圆角 = 外层圆角 − 间隙**，结果须落在集合内；间隙 ≥ 外层圆角时里层取 4 或 8。例：面板 16 内缩 8 的选中行 = 8；分段控件 8 内缩 4 的滑块 = 4；面板 16 内的警示条、小卡（间隙 16 ≥ 16）= 8。

### 投影（一套，两级）
- `--e1` 面板：`0 0 0 1px` 描边色 + `0 1px 2px` 轻投影。
- `--e2` 浮层（下拉、toast、抽屉）：`0 0 0 1px` 描边色 + `0 8px 24px` 投影。
- 按钮、输入、徽标无投影。
