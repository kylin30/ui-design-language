# 后台设计语言 · STYLE.md v30.0（R28「临摹」）

> 唯一样式表：`app.css`。令牌来自六张逐像素复刻（Linear 客户页、Stripe 发票列表、Attio 人员表、Sentry 问题流、Plain 工单三栏、Vercel Observability）和 43 张已上线产品截图的测量，见 `spec.html`「案例库结论」「六张逐像素复刻」「复核记录」与 `cases.md`。
> 方向：Linear 式（方向 A）· 鸢尾强调色 · Geist 数字 · 只用无衬线 · 分组明显 · 控件全平 · 低视觉噪音 · 无绿色识别色。

## 1. 外框
- 外框与侧栏同色 `--color-frame #F7F7F8`；工作区是**一整块白面板**：外边距 8、圆角 10、1px `--color-line`。
- 面板内：顶栏 48 → （页签 40）→ 工具栏 44 → 内容。区域之间各一条 1px 线，不用灰缝，不放浮动卡片。
- 列表—详情用 `.split`（左列宽 `--w-list`，中间一条线）；三栏用 `.split.three`（右栏 300）；记录页用 `.split.rec`（右侧属性栏 300）。

## 3. 规则
1. **一块白面板，区域之间用线**（不用灰画布 + 卡片）。
2. **单行 40px**，副信息进右侧固定列；只有成对信息（名称 + 邮箱、标题 + 服务名）才用两行 `.row.two`。
3. **列表用色带分组，记录页用标签 + 线**：长列表组头是 36px 贯穿色带 `.gh.band`（状态图标 + 名称 + 计数，可折叠 `.fold`）；记录页里的小分组是 12px 标签 + 计数 + 拉满的 1px 线（`.gh` / `.gh.in`），组前 16，组间距 > 组内距。
4. **状态颜色只给 14px 图标**（`.si` 空心 / 半满 / 四分之三 / 红圈叹号 / 灰色实心勾）；文字不染色，红色只给越线数字和危险操作。
5. **记录页用属性行**（`.props`：12px 灰标签 / 13px 值，列间 40），不用指标卡。
6. **表格只有横线**；金额右对齐，¥ 与角分降一级灰；编号等宽；表头 12px 次要灰、无底色。
7. **控件全平**：28px、圆角 6、1px 描边、无渐变无投影；主按钮纯鸢尾；投影只给菜单、命令面板、Toast、提示。
8. **看板指标用统计条**（`.stats`，竖线分格；数字 24/500）。
9. **详情面板里的分隔线收进内容边距**（左右 24）；只有顶栏、工具栏、面板交界贯穿。
10. **完成即退场**：已完成 / 已恢复 / 已上线一律灰色实心勾（`.si.done` = `.si.ok`），标题降为次要色（`.row.past`），时间进右列；全站只有一种完成态。
11. **图表从 0 起、3 个刻度、数据要密**：0 线用 line-strong；1.5px 线 + 7% 平涂面积，无点无渐变；用真实粒度（如 7 × 24 小时）；迷你柱一律灰色（`.mini.t`），严重度只用状态图标。
12. **高频操作写出快捷键**：队列流转（J / K、1–3、Enter、E、Z）都在按钮或选项旁放 `kbd`；一个键只做一件事。
13. **选中谁，详情就是谁**：每个可点条目有自己的详情 / 明细 / 抽屉；计数前后一致（页签 = 组内条数 = 页脚）。
