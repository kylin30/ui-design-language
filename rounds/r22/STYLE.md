# 后台设计语言 v24.0 · Round 22「成组」

方向 A「精简」+ 轻容器。这一轮只解决一件事：页面元素哪些是一组，不用读、眯眼就看得出来。研究与诊断见 grouping.md。

## 原则
1. 成组：组内间距不超过组间的一半（组间 ÷ 组内 ≥ 2）；间距由内向外逐层加大。
2. 一个对象一个面板：标题、内容、操作同在一块白色面板里；面板里不再套面板，最多一层浅底“井”。
3. 两层底色：浅灰画布 + 白色面板（1px 描边、圆角 12）。分组优先靠间距，只有“对象”才配容器。
4. 好读（继承 R21）：正文 15、近黑；每屏一个焦点；次要信息悬停或展开才出现。
5. 单色：鸢尾只用于主操作、选中和焦点；状态是圆点 + 文字；黄色只做小点缀。
6. 键盘：⌘K 命令面板，G + 字母跳页。

## 间距刻度（关系令牌）
| 令牌 | 值 | 用在哪 |
|---|---|---|
| --gap-pair | 4 | 标签↔值、标题↔说明、数字↔单位 |
| --gap-item | 8 | 按钮组、筛选控件、图标↔文字 |
| --gap-field | 16 | 字段之间、井内行距 |
| --gap-group | 24 | 面板内两组（结论 / 事实 / 明细） |
| --pad-panel / --gap-panel | 20 / 20 | 面板内边距；面板之间露出画布 |
| --gap-section | 32 | 页头↔第一块面板、大区块之间 |

## 容器
- 画布 #F0F0F3；面板白底、描边 #E1E1E7、圆角 12、阴影 0 1px 2px rgba(17,17,20,.03)。
- 面板头 56（标题 16/600 + 发丝线），面板体内边距 20，面板底（操作条）用浅底 #F7F7F9。
- 井（字段组）#F7F7F9、圆角 8、内边距 14/16；面板里最多一层。
- KPI 合成一块面板，格子之间竖线分隔。
- 列表与详情各一块面板，中缝 20；页签放进列表面板头（高 52）；详情面板高度贴合视口，头和操作条钉住，内容在面板里滚动。
- 工具条：筛选一组靠左（间距 8），操作一组靠右；放在表格面板内的浅底条上。

## 尺寸
- 字号：页标题 26/600，面板标题 16/600，组标题 13/600，正文 15/24，KPI 30/600，最小 13。
- 控件高 32、圆角 6；表头 40、行 46；列表行内边距 14/20；首末列内边距 20。
- 布局：顶栏 48，侧栏 232（与画布同底、无分隔线，选中项为白色胶囊），页边 40。

## 颜色（iris 默认）
- 文字 #111114 / #3E3E46 / #5C5C66；主色鸢尾 #6246EA；选中行 3px 鸢尾左条 + 6% 鸢尾底。
- 其他主题：面板描边 = --color-border，井 = surface-subtle；midnight 为深色。

## 字体
- 只用无衬线。数字用自托管 Geist（Geist Fig）；Geist Mono 只用于代码。

## 主题
- 默认鸢尾，另有 cobalt、lake、graphite、daylight、coral、midnight（深色）。换主题只换色值，不改结构。
