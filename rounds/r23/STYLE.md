# 后台设计语言 v25.0 · Round 23「精修」

方向 A「精简」+ 轻容器，沿用 R22「成组」的画布 + 面板和间距档。这一轮把六个演示当成已上线的产品，和 Linear、Stripe、Vercel、Attio、GitHub、飞书管理后台、Polaris 的真实截图并排审计，修掉 28 处“费劲 / 像演示 / 没磨好”的地方，并把页头、面板头、工具条、字段组收成 8 个组合。审计见 audit.md、audit/*.png。

## 原则
1. 组合：同一种东西每页长一样。页头、面板头、页签头、对象头、工具条、字段组、列表行、分栏只有 C1–C8 八种写法。
2. 一个焦点：每屏最多一个鸢尾主按钮（当前对象的主操作）；红色只给超时类状态，不进标题、说明、指标和图表。
3. 成组（继承 R22）：组内间距不超过组间的一半；一个对象一个面板；面板里最多一层浅底“井”。
4. 数据前后一致：页头统计、页签计数、表格行数、分页总数说的是同一个数，并随操作实时更新。
5. 单色：鸢尾只给操作、选中、焦点；图表数据用中性灰；状态 = 圆点 + 文字；黄色只做小点缀。
6. 键盘：⌘K 命令面板，G + 字母跳页，J / K 上下条，E 执行，Z 撤销。

## 8 个组合
| # | 组合 | 结构 | 尺寸 |
|---|---|---|---|
| C1 | 页头 | 标题 + 一行统计（工作台）或一行元信息（总览）；右侧按钮组，最多一个主按钮 | 标题 26/600；统计 14，数字 600；到内容 24 |
| C2 | 面板头 | 标题 + 灰色补充；右侧轻按钮 / 下拉 | 52 高，标题 16/600，左右 20 |
| C3 | 页签头 | 页签就是面板头；计数灰色 13；右侧排序下拉 | 52 高，选中 2px 下划线 |
| C4 | 对象头 | 标题 + 一个状态 + 右侧“n / m”与上 / 下按钮 | 52 高，图标按钮 28 |
| C5 | 工具条 | 搜索 + 按钮式下拉一组靠左，结果计数靠右 | 56 高，控件 32 |
| C6 | 字段组 | 井里 3 列“标签在上、值在下”，或左标签右值 | 标签 13 灰，值 15；字段间 16 |
| C7 | 列表行 | 2×2：标题 / 时间，元信息 / 状态；时间常显 | 15 / 13，行内边距 14/20 |
| C8 | 分栏视图 | 5 栏列表面板 + 7 栏详情面板，同顶同底，各自滚动，整页不滚；详情底部操作条钉住 | 高 = 100vh − 48 − 页头 |

## 页型
- 工作台页（运营待办、运维告警、内容审核）：C1（统计行）→ C8。不再放 KPI 格。
- 总览页（订单售后、数据看板、客户管理）：C1（元信息）→ 指标面板（四格一块，各页同高 139）→ 主体面板。

## 间距刻度（继承 R22）
| 令牌 | 值 | 用在哪 |
|---|---|---|
| --gap-pair | 4 | 标签↔值、标题↔说明 |
| --gap-item | 8 | 按钮组、筛选控件、图标↔文字 |
| --gap-field | 16 | 字段之间 |
| --gap-group | 24 | 面板内两组；页头↔内容 |
| --pad-panel / --gap-panel | 20 / 20 | 面板内边距；面板之间 |
| --gap-section | 32 | 大区块之间 |

## 尺寸
- 字号只有 7 档：12（图表刻度）/ 13（辅助）/ 14（控件、表格）/ 15（正文）/ 16（面板标题）/ 26（页标题）/ 28（指标数字）；数字一律 tabular-nums。
- 面板头、页签头、对象头 52；工具条 56；控件 32、圆角 6；表头 13/500；首末列内边距 20。
- 布局：顶栏 48，侧栏 232，页边 32，12 栏、栏距 20；面板内容左缘对齐（指标标签、列表行、表格首列同一 x）。

## 容器
- 画布 #F0F0F3；面板白底、描边 #E1E1E7、圆角 12。
- 井 #F7F7F9、圆角 8；面板里最多一层。
- 下拉统一为按钮式 `.dd`（弹出菜单、单选勾、↑↓ / Esc），不用原生 select；表单里的 select 去掉系统外观。
- 表格：ID 列等宽数字，金额右对齐，行尾悬停出现“⋯”。

## 交互状态
- 悬停：行底 surface-subtle；选中：3px 鸢尾左条 + 6% 鸢尾底；键盘焦点：2px 鸢尾 focus-visible 环。
- 空状态与列表顶部对齐，给出下一步信息。

## 颜色（iris 默认）
- 文字 #111114 / #3E3E46 / #5C5C66；主色鸢尾 #6246EA。
- 图表数据条用文字色 38% 混白；需要强调的数据段用 48% 深灰，不用鸢尾、不用近黑。

## 字体
- 只用无衬线。数字用自托管 Geist（Geist Fig）；Geist Mono 只用于代码。

## 主题
- 默认鸢尾，另有 cobalt、lake、graphite、daylight、coral、midnight（深色）。换主题只换色值，不改结构。
