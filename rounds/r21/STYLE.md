# 后台设计语言 v23.0 · Round 21「舒展」

方向 A「精简」。这一轮的目标是读起来不费力，诊断见 reading.md。

## 原则
1. 好读：正文 15 号、接近黑色；每屏只有一个焦点；次要信息悬停或展开才出现。
2. 少而清楚：列表每行最多 3 项信息，表格最多 7 列；分组靠留白和极浅底色，不靠满屏细线。
3. 单色：鸢尾只用于主操作、选中和焦点。状态写成圆点加文字；同屏最多出现一处红色异常。
4. 键盘：⌘K 打开命令面板，G + 字母跳页，J / E / Z 流转。快捷键提示放在命令面板里，不贴在按钮上。

## 尺寸
- 字号：
  - 页标题 26/600，区块标题 17/600，详情标题 19/600。
  - 正文 15/24，段落行高 1.7；列表标题 15.5/500，说明 14/22，表格 14.5。
  - KPI 30/600。最小字号 13，只用于时间和单位。
- 控件高 32，圆角 6；表头 40，表格行 46，列表行内边距 14，侧栏项 34。
- 布局：顶栏 48，侧栏 232，页边 40，区块间距 40；KPI 带圆角 12。

## 颜色（iris 默认）
- 文字：#111114 / #3E3E46 / #5C5C66（对白底对比度 18.8 / 10.6 / 6.6:1），禁用文字 #A8A8B0。
- 底色：分组浅底 #F7F7F9，悬停 #F2F2F5。线条：发丝线 #EAEAEE，分隔线 #F0F0F3。
- 主色：鸢尾 #6246EA。选中态用 7% 鸢尾底色，加一条内缩的圆角指示条。
- 图表只用灰和鸢尾，只有异常数据用红。

## 字体
- 只用无衬线。数字用自托管的 Geist（Geist Fig）；Geist Mono 只用于代码。

## 主题
- 默认鸢尾，另有 cobalt、lake、graphite、daylight、coral、midnight（深色）。换主题只换色值，不改结构。

- 样式：shell.css、minimal.css、reference-tokens.css。
- 脚本：themes.js、theme-switcher.js、theme-switcher.css、fb-dock.js。
- 字体：fonts/。
