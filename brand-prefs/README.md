# CPS 品牌 LOGO 偏好调研页

内部品牌偏好调研用：Xiang 点选喜欢的大厂/产品标志，复制结果发给马维斯 → 设计师据此精修 CPS LOGO。

## 本地路径
`/workspace/cps-logo/brand-prefs/index.html`

## 线上（GitHub Pages）
`https://kylin30.github.io/ui-design-language/brand-prefs/`

仓库目录：`kylin30/ui-design-language` 根下 `brand-prefs/`（不要放进 `ui-site/`）。

## 使用
1. 打开页面，按标签筛选（支付/游戏/社交/工具），点击卡片多选。
2. 点「提交选择」。
3. 点「复制给马维斯」，把文本发给马维斯（或设计师）。
4. 也可下载 `cps-brand-picks.json`，或分享带 `#ids=…` 的 URL。

选择保存在 `localStorage` 键 `cps-brand-prefs-v1`。
